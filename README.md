# GiftCard Wallet

A Flutter application for securely storing and managing digital gift cards using Firebase Authentication and Cloud Firestore.

## 📱 Project Overview

GiftCard Wallet is a mobile application developed using Flutter and Firebase. It allows users to securely sign in with Google and manage their gift cards digitally. Users can add, view, edit, search, and delete gift cards from a single place.

This project demonstrates the implementation of CRUD (Create, Read, Update, Delete) operations with Firebase Firestore and Google Authentication.

## ✨ Features

- Google Sign-In Authentication
- Firebase Authentication
- Cloud Firestore Integration
- Add Gift Cards
- View Gift Cards
- Edit Gift Cards
- Delete Gift Cards
- Search Gift Cards
- Responsive User Interface
